# L2 · 阶梯：角色、字号、行高、字重、字距

这一层给数值。数值不是唯一正确答案，但**必须只有一套**。选一套主参考（Carbon、Fluent、Ant 或本文），其余系统只用来补缺口；混用会得到 15px、17px、22px 这类谁都不认识的中间值。

## 1. 阶梯怎么来

一条可用的阶梯要同时满足三件事：

1. **相邻可辨**：相邻两级差异 ≥15%（视觉上能命名）。
2. **数量克制**：产品界面 5 级，营销页最多 7 级。
3. **落点整齐**：字号落在整数 px；标准/紧凑阶梯优先偶数（12/14/16/18/20/24/28/32/40/48），阅读密度允许 13/15 这类奇数，但同一密度内必须成体系。行高落在 2px 或 4px 网格上。

不建议用单一比率（如 1.25）机械生成全部字号：小字号处会产生 12.5、15.6 这类值，大字号处又不够跳。**底部密、顶部疏**的非等比阶梯更好用。

三套现成阶梯（与 SKILL.md 的密度一一对应）：

| 用途 | 阶梯（px） | 比率 |
|---|---|---|
| 产品 / 标准 | 12 · 14 · 16 · 20 · 28 · 48 | 1.17 / 1.14 / 1.25 / 1.4 / 1.71 |
| 阅读 / 文档 | 13 · 15 · 18 · 24 · 32 | 1.15 / 1.2 / 1.33 / 1.33 |
| 紧凑 / 数据 | 12 · 13 · 14 · 18 · 24 | 1.08 / 1.08 / 1.29 / 1.33 |

紧凑阶梯里 12 与 13 只差 1px，靠**颜色和字重**区分（caption 用次要色 400，label 用主色 500），不要指望字号本身。

## 2. 行高

行高不是「字号的百分比」，是**字身之外需要的呼吸空间**。汉字撑满 em 框，拉丁字母只占 x-height 到 cap-height，所以：

> **中文行高 ≈ 英文行高 + 0.2**（同一字号、同一行宽下）

按字号分段的取值范围：

| 字号 | 中文行高 | 英文行高 | 说明 |
|---|---|---|---|
| 12–13 | 1.5–1.6 | 1.33–1.4 | 辅助信息，不能再低 |
| 14–16 | 1.6–1.75 | 1.43–1.5 | 正文与 UI 主字号 |
| 18–24 | 1.5–1.6 | 1.33–1.4 | 引言、二级标题 |
| 28–40 | 1.35–1.45 | 1.2–1.3 | 页面标题 |
| 48+ | 1.15–1.3 | 1.05–1.15 | 展示字，允许紧凑 |

两条附加规则：

- **行宽越大，行高越高**：34em 的长行需要 1.7–1.8；20em 的窄栏 1.5 就够。
- **字号越大，比率越小**：28px 用 1.43（40px 行高），48px 用 1.17（56px）。

行高一律写**无单位倍数**，不要写 px。这样字号变化时行高会跟随，用户放大字体时也不会挤压。

## 3. 字重

只用四档：400 / 500 / 600 / 700。产品界面实际只会用到前三档。

| 字重 | 用途 | 中文注意 |
|---|---|---|
| 400 Regular | 正文、表格、说明 | 默认 |
| 500 Medium | 标签、按钮、强调、激活态 | 中文的「强调」首选，视觉增量温和 |
| 600 Semibold | 标题、关键数字 | 中文字体常缺此档，可能被替换为 700 |
| 700 Bold | 展示字、极少数强强调 | 中文大字号会糊，≥28px 慎用 |

规则：

- 一屏不超过 3 档。
- **不要用 600 配微软雅黑**：它的字重只有 Light/Regular/Bold，500/600 会被映射成 400/700，得到「要么没变、要么过粗」。要么用 400/700，要么换可变字体。
- 300 Light 只用于 ≥32px 的展示字，且只在深色底上更安全。
- 可变字体可以连续调，但 token 仍只暴露离散档位，避免 437 这种值。

## 4. 字距（tracking）

字距是**光学修正**，不是装饰。拉丁字母在大字号下需要收紧，小字号下需要放松；汉字相反，任何非零字距都会破坏方块节奏。

| 场景 | 拉丁 | 中文 |
|---|---|---|
| 正文 13–16px | 0 | 0 |
| 小字 ≤12px | +0.01em | 0 |
| 大标题 28–40px | -0.01 ~ -0.02em | 0 |
| 展示字 48px+ | -0.02 ~ -0.03em | 0 |
| 全大写标签 | +0.05 ~ +0.08em | 不适用 |
| 品牌字标 | 按字体调整 | 可 +0.02 ~ +0.05em，仅限字标 |

**不要对中文正文用负字距**。汉字的设计留白（sidebearing）是字形的一部分，收紧会让笔画相撞；也不要对中英混排的容器统一设 `letter-spacing`，否则英文被收、中文被挤。需要时用 `:lang(en)` 单独作用。

## 5. 响应式

- 根字号保持 `100%`，不要给 `html` 设 px。全部用 rem，用户改浏览器默认字号时才能整体缩放。
- **正文不要 fluid**：`clamp()` 让 16px 变成 15.2px 这种值，破坏阶梯。正文只在断点处换密度（standard → compact）。
- **展示字可以 fluid**：`clamp(2.5rem, 4vw + 1rem, 4rem)`，但上下限必须落在阶梯上。
- 断点建议只分两档：`≤640px`（紧凑/移动）与 `>640px`（标准）。不要为每个设备写一套字号。
- 200% 缩放时不允许出现横向滚动、截断或重叠（WCAG 1.4.4）。

## 6. 行宽与对齐

- `max-inline-size: 34em`（约 34 汉字 / 68 拉丁字符）。
- 可接受区间 30–36em；窄栏 24–28em；宽屏阅读区不要超过 40em。
- 左对齐；两端对齐只用于中文长文，并配合 `text-spacing-trim` 与 `line-break: strict`。
- 标题用 `text-wrap: balance`，段落用 `text-wrap: pretty`（渐进增强，不支持的浏览器忽略）。

## 7. 数字

- 表格、金额、统计卡：`font-variant-numeric: tabular-nums lining-nums`，保证数位对齐。
- 正文：比例数字（默认），阅读更顺。
- 不要用全角数字（１２３），不要用中文数字替代 UI 里的数值（「三」vs「3」）。
- 小数对齐、千分位、百分比、单位空格按 L3 的规则。

## 8. 常用字号决策

| 需求 | 选择 | 不要 |
|---|---|---|
| 密集后台正文 | 14/22（中）14/20（英） | 13/18 |
| 长文正文 | 16–18 / 1.7 | 14/1.4 |
| 表格单元格 | 与正文同字号，行高 1.5 | 单独 13px |
| 按钮 | label 14/20，高度 32–40 | 16px 按钮文字 |
| 表单标签 | label 14/22 | caption 12 |
| 帮助文字 | caption 12/18 | 与正文同大小 |
| 页面标题 | page 28/40 | 32/36 混搭 |
| 卡片标题 | 16/24 600 或 14/20 600 | 18/22 |
| 图表轴标签 | caption 12/16 | 10px |

## 9. 自检指标

在 DevTools 里跑一遍，或用 `templates/audit.mjs`：

```js
// 统计当前页面实际使用的字号与字重
const sizes = new Set(), weights = new Set(), families = new Set();
for (const el of document.querySelectorAll('body *')) {
  const s = getComputedStyle(el);
  if (!el.textContent.trim()) continue;
  sizes.add(s.fontSize); weights.add(s.fontWeight); families.add(s.fontFamily);
}
console.log({ sizes: [...sizes].sort(), weights: [...weights], families: [...families] });
```

目标：字号 ≤5（营销页 ≤7），字重 ≤3，字体族 ≤2。

## 10. 不要混用设计系统

Ant 的 12/14/16/20/24/30/38、Carbon 的 12/14/16/20/28/32/42、Fluent 的 12/14/18/20/28/40 各有逻辑。挑一套当主参考，另两套只用来回答「这个场景别人怎么处理」，不要各取一个数字拼在一起。拼出来的阶梯没有比率、没有命名、也无法解释。
