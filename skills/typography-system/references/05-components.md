# L5 · 组件：把角色落到具体控件

组件层只做一件事：**让正确的排版成为默认值，让错误的排版无法表达。** 如果按钮组件暴露 `fontSize` 属性，Agent 一定会传 15px；如果只暴露 `variant="primary|secondary"`，它就只能用 token。

以下尺寸以 Productive / 标准密度为基准；Reading 与 Compact 按 L4 替换字号，间距不变。

## 0. 组件契约

每个组件在类型层面声明自己接受哪些角色：

```ts
type TextRole = "page" | "section" | "body" | "label" | "caption";
// Button 只接受 label；Card 接受 section/body/caption；不暴露 fontSize
```

规则：

- 组件不暴露 `fontSize`、`fontWeight`、`lineHeight` 之类透传属性。
- 需要视觉变化时，暴露语义变体（`emphasis="strong"`、`tone="muted"`），内部映射到 token。
- 组件内不写裸值；所有字号来自 `var(--text-*)`。
- 一个组件内最多两个角色（如 Card：标题 + 正文）。

## 1. 页面框架

| 元素 | 角色 | 尺寸 | 间距 |
|---|---|---|---|
| 面包屑 | caption | 12/18 | 与标题间距 8 |
| 页面标题 | page | 28/40（中）28/36（英） | 下方 8 |
| 页面副标题 | body / label | 14/22，次要色 | 下方 16–24 |
| 页面操作区 | label | 14/20 | 与标题同一基线，右侧对齐 |
| 内容区起始 | — | — | 与 header 间距 24–32 |

规则：一页一个 `page`；标题不与面包屑同字号；操作按钮不抢标题的字重。

## 2. 标题层级

| 层级 | 角色 | 中文 | 英文 | 字重 |
|---|---|---|---|---|
| h1 | page | 28/40 | 28/36 | 600 |
| h2 | section | 20/30 | 20/28 | 600 |
| h3 | body + 600（小标题） | 16/26 | 16/24 | 600 |
| h4 | label | 14/22 | 14/20 | 600 |

h3 不新增字号：用 body 的 16px 加 600，行高取 1.5–1.6（中 26 / 英 24）。它是「body 的加粗变体」，不是第七个角色。

规则：

- 不跳级使用（h2 后不直接 h4）；视觉层级与 DOM 层级一致。
- 标题上方间距 ≥ 下方 1.5 倍（USWDS）。
- 标题不超过 2 行；超过说明文案太长或容器太窄。
- 中文标题不加字距；英文大标题可负字距（L2）。
- 标题不用 `text-transform: uppercase`（对中文无意义，英文长标题难读）。

## 3. 正文与 prose

- 正文 16/28（中）16/24（英），最大宽度 34em。
- 段落间距 1em；不用首行缩进。
- 段内强调只用 500 或颜色，不用斜体（中文）。
- 引用：左边框 2px + 左 padding 16，字号继承，颜色次要；不要整段斜体。
- 分隔线：1px，颜色为边框色的 60%；不要每条段落都加。

```css
.prose { font-size: var(--text-body-size); line-height: var(--text-body-leading); max-inline-size: 34em; }
.prose > * + * { margin-block-start: 1em; }
.prose :lang(zh) { text-autospace: normal; }
```

## 4. 列表

- 与正文同字号、同行高。
- 项间距 8；嵌套列表缩进 1.5em，不改变字号。
- 中文用「、」分隔行内枚举，块级用项目符号；不要混用。
- 有序列表的数字用等宽数字，右对齐标号。
- 列表项超过 4 行时，考虑改成小标题 + 段落。

## 5. 按钮

| 尺寸 | 高度 | 水平 padding | 字号 | 用途 |
|---|---|---|---|---|
| sm | 28 | 10 | 14/20 | 表格行内、紧凑工具条 |
| md | 32 | 12 | 14/20 | 默认 |
| lg | 40 | 16 | 14/20 | 表单主操作、移动端 |

规则：

- 文字用 label 角色，500 字重；中文 2–4 字，英文 1–3 词，句首大写。
- 不用 `letter-spacing`（中文会散）；全大写英文按钮只在极少数品牌场景。
- 图标与文字间距 6–8；只有图标时必须是 32×32 以上，并有 `aria-label`。
- 同屏只有一个主按钮；次按钮用描边或文字按钮。
- 按钮内不换行：`white-space: nowrap`；中文长文案改短，不要缩字号。
- 最小宽度 64；纯图标按钮 32。
- 触控目标 ≥44×44（移动端可用透明外扩）。

反例：`font-size: 15px` 的按钮、`letter-spacing: 1px` 的中文按钮、三个同等权重的主按钮。

## 6. 链接

- 字号继承正文；颜色对比 ≥4.5:1。
- 默认带下划线（`text-underline-offset: 2–3px`），不要只靠颜色区分。
- 行内链接不加字重；导航链接可用 500。
- 外链图标 12–14，与文字间距 4。
- 中文链接文字 2–8 字，英文 1–4 词；不要用「点击这里」。

## 7. 表单

| 元素 | 角色 | 尺寸 | 间距 |
|---|---|---|---|
| 字段标签 | label | 14/22，500 | 与输入框 8 |
| 必填标记 | caption | 12/18，强调色 | 与标签 4 |
| 输入框文字 | body / label | 14/22（桌面）16/24（移动） | — |
| 占位符 | 同上 | 同字号，次要色 | — |
| 帮助文字 | caption | 12/18 | 与输入框 4 |
| 错误文字 | caption | 12/18，错误色 | 与输入框 4 |

规则：

- 输入框高度 36–40；padding 8–12；文字垂直居中。
- **移动端输入框字号 ≥16px**，否则 iOS Safari 聚焦时自动放大页面。
- 标签在上方，不用 placeholder 代替标签（一旦输入就消失）。
- 错误信息放在字段下方，不用 tooltip；同时给 `aria-describedby`。
- 字符计数用 caption，右对齐；接近上限时变色，不改字号。
- 下拉选项与输入框同字号；选项高度 ≥32。
- 复选框/单选框的标签与正文同字号，点击区域包含标签。
- 多列表单的标签对齐方式统一：要么全部顶部对齐，要么全部右对齐，不要混。

反例：12px 的表单标签、14px 的移动端输入框、把错误信息做成红色 10px。

## 8. 表格

| 元素 | 角色 | 尺寸 | 说明 |
|---|---|---|---|
| 表头 | caption | 12/18（中）12/16（英），500，次要色 | 不用全大写 |
| 单元格 | body（紧凑） | 14/22（中）14/20（英） | 最小 12 |
| 数字 | 同上 + tabular | 右对齐 | 小数位对齐 |
| 行高 | — | 40–48 | 紧凑 32–36 |
| 单元格 padding | — | 8–12 垂直，12–16 水平 | 中文列更宽 |

规则：

- 表头与内容左对齐；数字右对齐；状态列居中或左对齐，全表统一。
- 斑马纹与网格线二选一；两者都有会显得吵。
- 长中文截断用省略号 + tooltip；不要缩字号硬塞。
- 列宽按内容 +20%；中文列最小 6em，英文列最小 8em。
- 排序、筛选控件用 caption 或图标，不要放大表头字号。
- 空表格给空状态，不要留一个只有表头的空壳。

## 9. 卡片

- padding 16（紧凑）或 24（宽松）。
- 标题 16/24 600（或 14/22 600）；正文 14/22；元信息 12/18。
- 标题与正文间距 8；正文与操作区间距 16。
- 卡片内不再嵌套卡片；需要分组用分隔线或背景色差。
- 整卡可点击时，标题用链接样式或整卡 hover，不要两套交互。

## 10. 导航

| 元素 | 角色 | 尺寸 | 说明 |
|---|---|---|---|
| 侧边栏项 | label | 14/20，500 | 高度 36–40，padding 8–12 |
| 分组标题 | caption | 12/18，500，次要色 | 不用大写 |
| 顶栏标签页 | label | 14/20，500 | 高度 40，间距 24 |
| 面包屑 | caption | 12/18 | 分隔符 `/` 或 `›` |
| 分页 | label | 14/20 | 按钮 32×32 |

规则：

- 激活态用「字重 500 + 颜色 + 背景」中的两项，不要只改颜色。
- 中文导航项 4–6 字；超过则截断 + tooltip，或改短文案。
- 导航不随页面滚动改变字号；不要做「滚动缩小」。
- 移动端底部导航标签 10–11px 是常见例外，但中文 10px 已难读，建议 11–12 并只放 4–5 项。

## 11. 徽标、标签、状态

- 徽标 12/18，高度 20–24，padding 0 6–8；中文 1–4 字。
- 状态点 + 文字时，点 6–8px，间距 6。
- 颜色不是唯一信息：状态同时用文字或图标（无障碍）。
- 不要用 10px 的徽标；不要给中文徽标加字距。
- 计数徽标用等宽数字，超过 99 显示 `99+`。

## 12. 提示与反馈

| 组件 | 标题 | 正文 | 宽度 |
|---|---|---|---|
| Tooltip | — | 12/18（中）12/16（英） | ≤240 |
| Popover | 14/22 600 | 14/22 | 240–360 |
| Toast | 14/22 600 | 14/22 | 320–400 |
| Alert | 14/22 600 | 14/22 | 容器宽 |
| 行内错误 | — | 12/18 | 字段宽 |

规则：

- Tooltip 只放短句，不放段落；触屏设备要另有触发方式。
- Toast 3–5 秒自动消失，可手动关闭；不要放需要用户决策的内容。
- Alert 的图标与文字基线对齐；标题与正文间距 4。
- 错误信息说「怎么修」，不要说「出错了」。

## 13. 对话框与抽屉

- 标题 20/28 600（紧凑 16/24 600）；正文 14/22；按钮 label。
- 最大宽度 480（表单）/ 640（内容）；移动端满宽减 32。
- 标题与正文间距 12；正文与操作区间距 24。
- 长内容内部滚动，不要把整个对话框撑高。
- 中文标题 ≤12 字；超过用副标题或正文。

## 14. 空状态与加载

- 标题 16/24 600；说明 14/22，最大 40em，居中 ≤2 行。
- 一个主操作，不要放三个按钮。
- 插画高度 ≤160；不要用大图挤压文案。
- 加载骨架的行高与真实内容一致，避免加载完成后跳动。
- 空状态文案要具体：「还没有项目，创建一个开始」优于「暂无数据」。

## 15. 代码、日志、JSON

- 13/20 mono，行高 1.6–1.7；容器 padding 12–16。
- 长行横向滚动，不自动换行；叙述性日志可换行。
- 行号用 caption，右对齐，等宽数字，不可选中。
- 中文注释在 mono 里占两格，属正常；不要用全角空格对齐。
- JSON 的 key 与 value 用不同颜色，但保持同一字号。

## 16. 图表

| 元素 | 角色 | 尺寸 |
|---|---|---|
| 图表标题 | label | 14/22 600 |
| 轴标签 | caption | 12/18（中）12/16（英） |
| 图例 | caption | 12/18 |
| 数据标签 | caption | 12/18（中）12/16（英） |
| 注释 | caption | 12/18 |

规则：

- 轴标签不低于 11px；中文轴标签 12px 起。
- 数字轴用等宽数字；千分位；单位放轴标题。
- 图例不超过 5 项，超出用交互筛选。
- 不要用 3D、阴影、渐变填充；数据墨水比优先。
- 颜色之外用形状/线型区分系列（色盲友好）。

## 17. 日期、时间、数字

- 列表中的时间用相对时间（3 分钟前），tooltip 给绝对时间。
- 表格中的日期用 ISO（2026-11-20），不要 `11/20/26`。
- 金额右对齐、两位小数、等宽数字；币种符号与数字之间不加空格。
- 大数字用千分位或万/亿，全站统一一种。
- 百分比与数字之间不加空格（30%）。

## 18. 搜索与高亮

- 高亮只改背景色，不改字号、字重、行高。
- 高亮颜色对比 ≥4.5:1；不要用纯黄底黑字以外的低对比组合。
- 匹配片段前后各留 20–30 字上下文，避免整段重排。
- 中文搜索不做词干处理；英文注意大小写不敏感。

## 19. 组件验收

- [ ] 组件不暴露任意字号/字重属性。
- [ ] 每个组件最多两个角色。
- [ ] 按钮、标签、表格单元格没有被压到 12px 以下。
- [ ] 移动端输入框 ≥16px。
- [ ] 长中文文案不会撑破布局或缩成小字。
- [ ] 空状态、错误态、加载态都有排版定义。
- [ ] 图标与文字基线对齐。
- [ ] 暗色模式下角色不变，只换颜色。
